# 🩺 AI Medical Assistant

An AI-powered Medical Assistant built using Streamlit, FAISS, Sentence Transformers, and Groq LLM API.  
The application helps users get symptom-based healthcare guidance through an interactive chatbot interface.

---

## 🚀 Live Demo

👉 https://ai-medical-assistant-gi7imvkzera2kzxzgctprj.streamlit.app/

---

## ✨ Features

- 🤖 AI-powered medical chatbot
- 🩺 Symptom-based assistance
- 🔍 Semantic search using FAISS
- 🧠 Sentence Transformer embeddings
- ⚡ Fast responses using Groq API
- 💬 Interactive Streamlit interface
- 📚 Retrieval-Augmented Generation (RAG)

## 🛠️ Tech Stack

- Groq API
